# TSW

Ejercicios y prácticas de la asignatura de Tecnologías y Servicios Web (TSW), centrados en el desarrollo de aplicaciones web.

## 📌 Contenido

- `Entrega1-MVCsaveYourMoney/`: Aplicación web utilizando el patrón MVC.
- `Entrega2-SPAsaveYourMoney/`: Aplicación SPA con enfoque en JavaScript.
- `todo-list-handlebars/`: Lista de tareas utilizando Handlebars.
- `todo-list-vanilla/`: Lista de tareas con JavaScript puro.

## 🛠️ Tecnologías

- JavaScript
- HTML
- CSS
- Handlebars
